## 四、核心成果精华：提问 3W1H1E 规范速查

为帮助学习者快速上手高质量技术沟通，本项目沉淀的核心提问规范提炼如下：

```
提问 3W1H1E 黄金法则：
├── [W1] What's Context    : 交代运行环境、系统版本与核心业务目标
├── [W2] What's Tried      : 明确列出已尝试且排除的方案（证明已做基础自查）
├── [W3] Where's Blocker   : 精确定位到具体技术冲突或架构权衡瓶颈
├── [H]  How to Reproduce  : 附带 <= 10 行自包含的最小可复现代码（MRE）
└── [E]  Evidence Attached : 附带关键 3-5 行错误日志或退出码（拒绝拍照乱码）
```
